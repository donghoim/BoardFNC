# FabricMaster ERP

원단 주문/회계/생산 및 재고 관리 ERP — 0→1 신규 런칭

- **기간**: 2021.05 – 2022.12 (1년 8개월)
- **역할**: PM/기획 — 모듈 구조 설계, DB 설계(월별 집계 테이블 분리, Soft Delete), SQL 작성·쿼리 튜닝, 통계 기획
- **구성**: PM/기획 3명 · 디자인 1명 · 개발 10명 · DB 2명 · QA 1명 (PM/기획 기준 본인 기여 30%)
- **Key Result**: 발주-생산 연동 100%, 원가 계산 오류 92%↓

## Why

제조사 원가·마진 데이터가 산재해 있었고, ERP 없이 수기로 관리하다 보니 오류가 잦았습니다. OneFabric과 데이터가 단절돼 있어 발주부터 생산, 출하까지 이력을 추적할 수 없었습니다.

## Approach

원가관리·발주생산·출하재고·통계대시보드 4개 핵심 모듈로 구조를 설계했습니다. 월별 집계 테이블을 분리해 대량 데이터 조회의 성능 한계에 대응하고, Soft Delete 정책으로 감사 이력을 보존하며 ERP와 OneFabric을 동기화했습니다.

## Key Decisions

| 대안 vs 대안 | 판단 기준 | 결정 | 결과 |
|---|---|---|---|
| 실시간 집계 vs 월별 집계 테이블 분리 | 거래량이 늘면서 실시간 집계 시 쿼리 성능 한계 발생 | 월별 집계 테이블 분리 | 쿼리 성능 저하 위험 감소 |
| Hard Delete vs Soft Delete | 원가·거래 데이터는 감사 이력 보존이 법적으로 필요 | Soft Delete 정책 채택 | 법적 요건 충족, 이력 추적 가능 |
| 실시간 동기화 vs 배치 동기화 | 실시간 동기화는 운영 중 부하 발생 우려 | 야간 배치 스케줄러로 OneFabric과 동기화 | 이중 입력 제거, 운영 중 부하 위험 감소 |

## Output

- 발주-생산 연동 100% (이력 추적 완전 자동화)
- 원가 계산 오류 92%↓ (수기 대비)
- 마진율 조회 실시간 (배치 집계 → 즉시 계산)
- 평균 마진율 18.3% (엑셀 수기 관리 → 자동화)
- 배포 후 1개월 내 100개 이상 입점 계약 체결, 등록 상품 DB 5만건 이상 확보 (2024 자료)
